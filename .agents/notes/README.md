# .agents/notes —— 决策记录

放「为什么这么定、被谁取代」，不放流水账。

## 生命周期

| 目录 | 含义 | 约束力 |
|---|---|---|
| `proposed/` | 提议中，等用户裁定 | 无约束力，不可据此实现 |
| `implemented/` | 已落地（用户裁定 / 代码已按此实现） | 有效；被取代时移入 `archived/` |
| `archived/` | 被取代 | 仅历史留痕，头部写 `取代者：<路径>（YYYY-MM-DD）`，勿据此开工 |

## 命名

`<分类>/YYYY-MM-DD-<slug>.md`，分类如 `architecture/`、`product/`、`process/`。

## 形制（建议）

1. 背景与用户原话（逐字，带日期）；
2. 已确认事实（`path:line` / 上游版本号）；
3. 选项与取舍（为什么淘汰其他选项）；
4. 裁定（谁、何时、依据）；
5. 影响面 / 后续任务。
